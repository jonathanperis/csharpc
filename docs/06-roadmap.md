# 06 — Roadmap

Status legend: ✅ supported (differential-tested against .NET 11) · 🟡 partial · 🚧 in progress (branch open) · ⬜ planned · ❌ out of scope (same limits as NativeAOT)

The measuring stick is the conformance corpus ([09-conformance.md](09-conformance.md)): **100 %** of 195
feature programs at the time of writing (41 % at the start of the day), with **zero wrong-output cases** —
every failure is a clean "not supported by csharpc yet" diagnostic.

## Feature-support matrix

## Milestones

### M0 — Spike ✅ (2026-10-22, morning)
Roslyn front-end, CFG → LLVM lowering, csrt runtime, differential tests, docs.

### M1 — "Real programs" ✅ (2026-10-22, same day)
Structs, generics, interfaces, exceptions, closures, async/iterators, GC, records, spans, unsafe,
drop-in MSBuild integration, conformance corpus, benchmarks beating NativeAOT on CPU time on all 14
benchmark programs ([bench/RESULTS.md](../bench/RESULTS.md)).

### M2 — Self-hosted corelib (🚧)
The BCL surface written in C# and compiled by csharpc together with the program; library symbols that
Roslyn binds against the real reference assemblies are redirected to it. Collections and LINQ first,
then `System.IO`, `System.Text.RegularExpressions`, `System.Text.Json`.

### M3 — Toolchain quality (🚧)
DWARF debug info, multithreaded runtime, cross-compilation (aarch64, wasm32), Windows/macOS, faster
compiles (ship csharpc itself NativeAOT-compiled — or csharpc-compiled).

### M4 — Bootstrapping
csharpc compiles csharpc (and Roslyn).

### M5 — Binary packages
An IL front-end (IL → the same lowering IR) so NuGet packages without source can be linked in; the
source front-end remains the primary path.
