Two things the flip decides: (1) **Security (hash flooding, #285):** the string comparer family is csharpc's own (redirected contract classes, `corelib/UpstreamSupport.cs`) because upstream's reaches ICU casing and `GenericEqualityComparer`. As in .NET, `Dictionary<string,V>`/`HashSet<string>` with the default, `StringComparer.Ordinal` or `OrdinalIgnoreCase` comparer start on the fast non-randomized hash (`string.GetNonRandomizedHashCode`) and, once an operation meets more than 100 collisions, switch to a randomized comparer and rehash; `string.GetHashCode()` is Marvin seeded per process from the OS random number generator (`getentropy`/`rand_s`; a failing generator stops the program), where it used to be a fixed multiplicative hash that an attacker could build collisions against. Sample 1308 forces the switch with colliding keys built from the documented hash (200 000 keys; without the switch it does not finish in minutes: checked by making the randomized hash the fast one, 40 s and still running) and `tests/hashseed.sh` checks that processes seed differently. Costs: `string.GetHashCode()` is Marvin (slower than the old hash on programs that hash strings with it; `Dictionary<string,V>` itself keeps the fast hash), `HashSet<string>`/`Dictionary<string,V>` net instructions `Dictionary<string,int>` 33.9 M to 33.1 M and `HashSet<string>` 31.0 M to 30.4 M (the C# non-randomized hash replaced the C one in the guard), binary +4 KB on a program with four collections. The wrappers for Ordinal/OrdinalIgnoreCase are made by those comparers, so a program that never creates them does not carry their code. (2) The throw helpers that format the key with `string.Format` are replaced (`csharpc` profile) by direct text for `string`, `int`, `long`, `uint`, `ulong` and `char` keys and `ToString`/`IFormattable` for the rest, so a program reading a Dictionary does not carry composite formatting and every number formatter. The size cost is the owner's call under the standing authorisation; a follow-up could replace the culture caches' Dictionaries with something smaller. |
