# The author-signing certificates the build accepts for the runtime packs it downloads (src/Csharpc/Csharpc.csproj,
# _CsharpcVerifyCoreLib32Pack), as NuGet's trustedSigners pins them: SHA-256 fingerprints of Microsoft's NuGet author-signing
# certificates, one per line. The build runs `dotnet nuget verify --all <nupkg> --certificate-fingerprint ...` with these and stops on an
# invalid signature, a changed package (integrity check) or another signer. Pinning the signer, not the package's hash, survives SDK
# patch updates (#382). When Microsoft rotates its certificate, add the new fingerprint after checking it on a package from nuget.org
# (`dotnet nuget verify --all <nupkg>` prints the author signature's subject and SHA-256 hash), and drop expired ones later.
